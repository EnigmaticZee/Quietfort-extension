Privacy

Adds the Sec-GPC: 1 header to every request and sets navigator.globalPrivacyControl on every page.

Other sites learn only which site you came from, not the page.

Chrome sends Google an identifier of its experiment configuration; this strips it.

On-device AI opt-in

These use the browser’s built-in language model on this device (Chrome’s Prompt API). Page content is never sent anywhere. Without the model they fall back to the rule-based checks described below.

Model: checking…

Finds blocks labelled “Sponsored”, “Anzeige”, “Sponsorisé”…, affiliate links and ad frames. Clear cases are hidden; unclear ones are asked to the model once per site layout (kept when there is no model).

Fake virus alerts, “call this number” support scams, browser lockers, crypto “giveaways”, urgent gift-card payments. Shows a warning with “Leave page”; never blocks.

Every click it proposes is checked: it must read as “reject all” / “necessary only” and never as accept, subscribe, pay or log in. Needs the model; does nothing without it.
